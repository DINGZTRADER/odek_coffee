# Odek Coffee Website

Premium static brand website for Odek Coffee, Uganda.

## Hosting
Prepared for Netlify Free hosting. Publish directory: repository root (`.`).

## WhatsApp receptionist
Edit the `ODEK_WHATSAPP` constant at the top of `app.js` to replace the prototype number with Odek Coffee's official WhatsApp number.

## Content facts used from the pack
- Single Origin
- Pure Robusta
- Origin: Odek, Omoro District, Acholi Sub-Region, Uganda
- Medium Dark Roast
- 250g
- Ground Coffee
- Product of Odek Farmers Ltd (Uganda)
- Brand story line: “Hope Grows in Odek”
